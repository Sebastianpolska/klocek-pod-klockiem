# Klocek Pod Klockiem (KPK)

Klasyczna gra w stylu Tetris napisana w języku [wpisz język, np. Python / JavaScript].

## 🎮 Sterowanie

| Klawisz | Akcja |
| :--- | :--- |
| **A** | Przesunięcie klocka w lewo |
| **D** | Przesunięcie klocka w prawo |
| **R** | Obrót klocka |
| **S** | Przyspieszenie opadania klocka |
| **Spacja** | Natychmiastowe zrzucenie klocka na dół |
